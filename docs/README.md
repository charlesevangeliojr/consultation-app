# App documentation

## Learn what the app does

Start with the **[App features and user guide](app-features.md)**. It explains the
features available to students, teachers, and administrators, what information
each person can manage, and how consultation requests move through the system.
It is written for people who want to understand the app without reading code or
following installation instructions.

The guide covers:

- Registration, LRN/email sign-in, and user profiles.
- Teacher discovery, calendars, availability, booking, and proposed times.
- Approval, cancellation, completion, history, and scheduling conflicts.
- School lists, teacher permission, accounts, roles, and branding.
- Online presence, last-seen activity, active/inactive status, and automatic inactivity.
- Privacy, mobile navigation, automatic updates, and common questions.
